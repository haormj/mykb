# Proposal

## Why

第一阶段已把后端改为知识库作用域，但前端仍保留全局的评测、审核、看板入口，也缺少「设置」与成员管理界面。本变更把已有能力收进知识库详情，并补齐设置/成员页，使"所有概念封装进知识库"在界面上真正闭环。

## What Changes

- 知识库详情整合为完整工作台：文档、知识、评测、审核、看板、设置。
- 新增「设置」页：知识库名称/分支等基础配置、远程仓库补绑（owner）、成员与角色管理。
- 新增成员管理界面：添加/移除成员、调整角色、转让 owner，并遵循能力矩阵。
- 移除全局评测/审核/看板入口，改为必须在具体知识库上下文内访问。
- 页面按当前用户角色隐藏无权操作。

## Impact

- **Frontend**: 知识库详情路由与 tab、设置页、成员管理组件、按角色的操作可见性；移除全局导航。
- **Backend**: 仅复用第一阶段的知识库、成员与作用域接口，不新增 spec 级行为。
- **Depends on**: `add-knowledge-base-foundation`，以及 `add-document-import-tasks`（文档页）。
- **Specs**: 无 spec 变更，本变更以 `skip_specs: true` 标记。
